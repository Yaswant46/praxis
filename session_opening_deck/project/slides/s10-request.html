How to ask for a character

The form

[Team] requests [Character] as primary for [objective], because [what the objective needs from them this quarter]. Secondary: [Character].

Worked example — a different programme

"Logistics requests the Fleet manager as primary for Delivery Cost, because the route plan can't be costed until we know which vehicles we actually have in March. Secondary: the Depot lead."

A request that isn't in this form doesn't reach them.

"A request that isn't in this form doesn't reach them." Say it twice. One primary, one secondary, entered in the app before requests lock — and spoken in this form in the room. The example is deliberately from another programme so it hints at nothing about who is right for what here.
